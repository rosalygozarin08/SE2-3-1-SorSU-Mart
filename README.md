# SorSU Mart 🛒

SorSU Mart is an innovative e-commerce platform designed specifically for the Sorsogon State University (SorSU) community, streamlining campus commerce by allowing students, faculty, and student entrepreneurs to buy and sell goods seamlessly. Built with a user-friendly interface and secure transaction features, the application serves as a centralized digital marketplace for academic supplies, university merchandise, food, and daily essentials. By bridging the gap between campus consumers and entrepreneurs, SorSU Mart enhances the overall university experience, fosters a self-sustaining campus economy, and promotes digital literacy within the institution.

## 🚀 Features

* **Tailored for SorSU:** Specifically built to meet the needs of Sorsogon State University students and faculty.
* **Student Entrepreneurship:** Empowering student-led businesses with a platform to showcase and sell products.
* **Centralized Marketplace:** Easy access to academic supplies, university merch, snacks, and daily essentials.
* **User-Friendly & Secure:** Designed with an intuitive interface and secure transaction features to promote digital literacy safely.
